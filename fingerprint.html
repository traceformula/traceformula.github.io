What your browser reveals to any website, without asking

This is browser fingerprinting. A page reads ordinary details about your device, then hashes them into a value that often stays the same even after you clear your cookies.

Everything runs in your browser. Nothing is sent or stored.

Nothing is read until you press the button. This page does not send the results anywhere, sets no cookies and uses no browser storage. Run it twice and the only memory of the first run is in this open tab.

To check, open your browser’s network panel and press the button: no request appears. The page’s Content-Security-Policy also sets connect-src 'none', so the browser itself refuses fetch, beacon and WebSocket connections from it. Loading any web page is still a request to its host, so GitHub Pages receives your IP address and User-Agent as usual. Those are not part of the results below.

How to read this

What this page cannot tell you

It cannot tell you how unique you are. That would take comparing your values with a large population of other browsers. This page has no such data and keeps none, so it shows no uniqueness score or percentage.

A hash alone says nothing about rarity. Two identical laptops can produce the same one, and your own can change after a browser update, a new monitor, a new font or a trip abroad.

Projects such as Cover Your Tracks and AmIUnique do compare, because they collect results from their visitors. Read their terms before you run them.

What each label means

Read: the browser returned a value. It may not be the true one, since browsers can report a substitute.

Not available: the feature is missing or turned off here.

Blocked: the feature ran, but what came back was empty or not what was drawn.

Randomized: repeated reads differ, or a solid colour area came back changed.

This page only spots noise that changes between reads. Noise that stays fixed for a session, as Brave’s does, shows as Read and still gives a different value on other sites.

What reduces fingerprinting

  • Tor Browser tries to make all its users look the same, with standard window sizes, a UTC time zone and limited canvas reads. It works best unmodified, because added extensions and changed settings can set you apart.
  • Firefox has privacy.resistFingerprinting in about:config, which applies protections that came from Tor Browser, including reporting UTC. Mozilla warns that it can break sites. Enhanced Tracking Protection separately blocks scripts on a list of known fingerprinters, which is a milder step.
  • Brave adds small random changes to canvas, WebGL and audio results. They stay fixed for each site during a session, so sites get different values from each other and new ones after a restart.
  • Safari 17 and later turns on advanced fingerprinting protection in Private Browsing, and it can be set for all browsing.
  • What does not help much: clearing cookies and private windows leave most of these signals as they were, and a VPN changes your IP address but not these values. No setting removes fingerprinting completely.
