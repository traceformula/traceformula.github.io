# Piano Practice Tools

Free, open-source browser tools for learning piano.

- **[Ear Trainer](https://traceformula.github.io/piano/ear-trainer/)**: recognize notes, intervals and melodies by ear, including Für Elise phrases.
- **[Note Reader](https://traceformula.github.io/piano/note-reader/)**: read treble and bass clef notes, either by naming them or by finding the key on the piano. Tracks accuracy and speed.
- **[Fingering Coach](https://traceformula.github.io/piano/fingering/)**: finger numbers, five-finger positions, thumb-under and position-shift exercises, and Für Elise fingering, with a watch-and-tap mode for practising on a table.
- **[Play by Ear](https://traceformula.github.io/piano/by-ear/)**: hear the opening of 290 public-domain tunes from around the world (children's songs, folk, carols, hymns, anthems, classical), filterable by country, then find the notes on the keyboard.

The tools use adaptive drills that bring up weak items more often, suggest when to level up, and save progress in your browser. Shared code lives in `shared/`.

Plain HTML, CSS and JS with no build step.
